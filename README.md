# Flow Messaging SDKs

Let AI agents talk on WhatsApp, Telegram and iMessage through one API at
`api.flow.engineer`.

- [`openapi/openapi.yaml`](openapi/openapi.yaml): the OpenAPI 3.1 spec, the API's
  contract and the source of the SDKs and the API reference.
- `typescript/`, `python/`, `go/`: SDKs (coming; TypeScript first).
- `docs/`: documentation source (coming, docs.flow.engineer).

The API is in beta. Licensed under Apache-2.0 (see [LICENSE](LICENSE)).
