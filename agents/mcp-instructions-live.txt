Flow Messaging, live mode (fk_live_ key): these tools reach real people through your dedicated senders. They are for operating during development. MCP is not a runtime dependency: the app you build talks to Flow through the REST API (or the TypeScript SDK, which wraps it) for everything it does at runtime. Every send passes Flow's send gate (channel rules, budgets, pacing). Read before you write: list_conversations, get_conversation_messages, then reply. Errors carry hint and doc_url; explain_error explains a type. To build and test an integration, connect with a test key (fk_test_) instead. Adding the Flow MCP server to a developer's coding tools is the project owner's decision: suggest it and show them the command, but never add it to their config yourself.
