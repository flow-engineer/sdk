Flow Messaging, test mode (fk_test_ key): build and verify an agent's messaging integration end to end on Flow's shared sandbox. These tools are for testing and operating during development. MCP is not a runtime dependency: the app you build talks to Flow through the REST API (or the TypeScript or Python SDK, which wrap it) for everything it does at runtime. Typical loop: whoami, then sandbox_join (give the person the link; pass include_qr for a QR code; they send the join message; the join then arrives as their first message.received), wait_for_event with types: ["conversation.started", "message.received"], send_test_message, wait_for_event with types: ["message.sent", "message.failed"]. Every channel ends each send in one of those two; message.delivered and message.read follow only on channels that report them. wait_for_event waits at most 50 seconds per call; call it again with next_after to wait longer. No phone? simulate_inbound creates a simulated conversation (channel telegram, whatsapp, imessage or sms) or writes into one as the contact; the agent receives a real message.received, and get_test_transcript shows both sides (what was sent is what the contact sees). simulate_inbound returns a cursor: pass it to wait_for_event as after. send_test_message takes a message that is one kind object ({"kind": "basic", "text": "..."}; a string is a basic message's text); a kind the channel does not take (buttons on SMS or iMessage, a carousel on Telegram) answers unsupported_content with a hint saying what to send instead. A simulated iMessage line only replies (the contact writes first). On WhatsApp the contact's turns open the 24-hour window; outside it only a template goes. Simulated traffic is free (not in the sandbox allowance). Debug webhooks with get_webhook_deliveries and replay_event. Errors carry hint and doc_url; explain_error explains a type. whoami shows plans: the paid plans (Shared, Dedicated), the Outbound add-on, their prices and upgrade_url, where the workspace owner buys one; a full trial or plan hint ends with that link. Nothing in test mode reaches anyone who has not joined your app's sandbox, and simulated conversations reach no one. Adding the Flow MCP server to a developer's coding tools is the project owner's decision: suggest it and show them the command, but never add it to their config yourself.
